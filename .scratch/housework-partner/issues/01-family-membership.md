## Question

- 创建、邀请、接受邀请的用户路径；只有一位成员时能使用哪些功能。
- 同一账号允许加入几个家庭；重复邀请、家庭已满和误加入如何处理。

## Answer

### 账号、家庭与邀请

- 一个个人账号同时只能属于一个使用中的家庭；归档历史访问不占用当前家庭名额。首版家庭最多两位伴侣，账号只能代表本人，不支持切换身份或代打卡。
- 首次进入选择创建家庭或接受邀请；已有使用中的家庭时，不得直接加入另一家庭或覆盖原关系。
- 通过微信分享邀请卡片。受邀人查看邀请人和家庭名称后主动确认加入；邀请有效期 24 小时，可撤销、重新生成，成功加入后失效，家庭满两人后不再接受加入。
- 失效邀请不能完成加入，需要使用有效邀请；再次打开已使用的邀请不产生新的成员关系。归档家庭不接受邀请加入。

### 双方权限与单人起步

- 双方平等、不设家主，都能调整家务安排和修改家庭名称；个人昵称、头像由本人修改。不得单方面踢出伴侣。
- 伴侣加入前可以载入家务、安排任务和本人打卡；天平显示等待伴侣加入。轮流分工、给伴侣比心和兑换伴侣提供的特权待双方加入后开放。
- 单人期间如何获得积分由[贡献积分与可用积分如何计算和更正](05-points-ledger.md)决定，不在本工单预设计分结果。

### 退出与家庭整体归档

- 本人可主动退出，无需伴侣批准；退出前明确说明将结束双方在此家庭的协作、旧家庭无法恢复，并再次确认。退出结果在小程序内告知另一方。
- 未兑换积分与未履约心愿不阻止退出。一方确认退出即使原家庭整体归档，停止新增打卡、兑换和继续接纳成员，双方可重新创建或加入家庭。
- 原家务记录、留言、贡献、钱包明细和兑换历史保留供原成员查看；新家庭重新开始，记录和积分不迁移，新伴侣无法查看旧家庭内容。
- 双方原钱包余额保留可查但停止消费。未完成兑换自动取消，已扣积分退回原兑换人的归档钱包，保留“家庭归档，兑换已取消”的原因；已兑现记录保留，双方不再收到相关履约提醒。
- 首版不提供归档恢复。即使仍是原两位伴侣重新使用，也需建立新家庭，不能把原家庭重新启用。
- “离婚”是讨论退出含义时的类比，产品使用家庭退出、归档等用语。

### 关键场景的预期结果

| 场景 | 预期结果 |
| --- | --- |
| 一人创建家庭，伴侣尚未加入 | 可先安排家务并本人打卡；需要伴侣的功能等待加入 |
| 受邀人已有使用中的家庭 | 不覆盖原家庭，不直接加入另一家庭 |
| 邀请过期、已撤销或已被使用 | 不能借此新增成员；过期或撤销后需获取有效邀请 |
| 家庭已有两人 | 不再接受第三位成员 |
| 一人误加入后决定退出 | 仍通过退出确认结束协作，原家庭归档；不另设踢人或恢复路径 |
| 有剩余积分及待履约兑换时退出 | 不阻止退出，完成归档、取消与退分；归档余额仅可查看 |
| 双方之后再次共同使用 | 新建家庭并邀请加入，原记录留在原家庭，不恢复或迁移 |

以上是已确认的产品预期，尚未经过实现或原型验收。
