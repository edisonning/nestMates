## Question

用一个可供用户反馈的粗原型，确定天平的指标、比例算法、视觉表现与提示方式，使双方看见贡献，同时接受约定的分工。

- “本期”采用什么时间范围，完成次数怎样作为辅助信息展示；遵守[打卡与反馈决议](04-checkin-and-feedback.md#answer)，天平比例按贡献分值计算，首版不设置耗时属性或劳作时长统计，不重新讨论以时长或次数替代贡献分值作为天平比例口径。
- 可用积分和兑换消费不得无意中改变历史贡献的含义，按已决积分规则验证。
- 是否需要记录家庭约定的分工目标；若需要，采用什么表达，如何避免暗示人人应各做一半。
- 验证贡献相近、明显不等、双方均为零和只有一位成员有记录时的天平；区分已配对但一人未打卡与[家庭生命周期](01-family-membership.md#answer)中的等待伴侣加入、归档历史状态。
- 倾斜、位置、比例数字与温暖提示如何共同传递天平感觉；不能只用普通排行榜替代。
- 用户确认比例表达和文字语气后再解决本工单，原型链接作为附件保存在工单。

## Answer

### 月份与指标

- 按北京时间自然月统计，从每月 1 日到月末；默认本月，支持切换查看已有记录的历史月份。记录归属沿用[积分决议](05-points-ledger.md#answer)的贡献统计日。
- 天平仅按双方所选月有效完成家务的贡献分值呈现比例。双方分别显示贡献积分、占比、完成次数，次数作为辅助信息，不设置耗时属性。
- 首版不增加家庭目标比例设置或达标判断，不要求五五开，不以谁落后、谁应该多做评价家庭成员。
- 可用积分和兑换明细放在积分相关入口，与贡献主指标区分。可用余额为全部历史收支形成的当前余额，不因切换贡献统计月而变成该月余额；消费和退款不改变天平比例。

### 已选布局与比例表现

- 采用 **B「双方对照」**：月份选择在上方；本人和伴侣的贡献数字并排展示，随后展示天平、温暖提示与该月家务记录。A「天平居中」和 C「月度记录」仅作为探索对照保留，不作为默认方案。
- 当双方总贡献大于 0 时，本人占比为本人贡献除以双方贡献之和，伴侣同理。界面显示整数百分比；采用互补显示使两者之和为 100%，不改变实际贡献分值。
- 天平贡献较多的一侧下沉，按双方贡献差占总贡献的比例线性映射倾斜程度，最大 13 度。几何倾斜使用实际比例，不以取整后的显示百分比反算；两侧贡献相等时居中。
- 本轮确认的温暖表达包括“每一份付出，都有重量”“一起照顾家的这些小事，都记在这里”“分工可以不同，每一份付出都值得被看见”。文字不催促、不排名、不判定达标。
- 后续整合页面沿用 B 的信息顺序与表达；原型控制台、手机外框和 A/B/C 切换条是体验工具，不成为正式小程序导航或业务功能。

### 特殊状态

| 状态 | 页面结果 |
| --- | --- |
| 双方贡献相近 | 显示真实分值与整数占比，天平随实际差异轻微倾斜，不判定是否达标 |
| 双方贡献差距明显 | 分多的一侧下沉，倾斜不超过 13 度，仍显示真实占比与温暖提示 |
| 所选月双方都没有有效完成 | 天平居中、贡献与次数为 0、占比为“—”，提示所选月份还没有家务记录，不伪造 50%/50% |
| 已配对但只有一人有贡献 | 显示 100%/0%，保留零贡献一方信息，不显示落后或催促文案 |
| 只有本人、等待伴侣加入 | 显示本人已记录的贡献与邀请入口，不显示双方占比；提示“你的付出，已经好好记下” |
| 家庭已归档 | 明确标注历史只读，可查看历史月份，不开放写操作 |
| 可用积分因更正为负 | 贡献仍按有效完成记录展示，负余额不当作负贡献，不改变天平比例 |

### 补记、更正与撤销在天平中的表现

- 补记填了过去完成日期时，贡献进入过去月份；未填日期时按原提交日进入对应月份。可用积分按实际提交成功时入账，两种时间不能混淆。
- 完成日期跨月更正时，从原月份移出贡献并加入新月份，累计贡献和可用积分不变；清空日期时按原打卡或补记提交日归属。
- 撤销从该记录所在月份移除贡献及完成次数，并按积分决议扣回原获积分；重新打卡只计算新有效记录，不与已撤销记录重复统计。
- 兑换或取消退分仅影响可用余额，贡献分值、完成次数与天平比例不变。
