## Question

用粗原型确定家庭管理、公共家务预设、默认特权模板、运行概况及管理员权限的页面结构与关键操作。

- 运营者从概况进入家庭状态处理或模板维护的路径。
- 家庭列表和详情的字段、筛选及必要动作，与已决隐私边界逐项一致。
- 模板新增、编辑、发布与下架时，对生效范围的说明是否足够清楚。
- 状态变更与其他会影响家庭使用的操作如何呈现结果、确认和恢复入口。
- 权限不足、无数据及操作失败时的显示；遵循[平台权限决议](09-admin-permissions.md#answer)，不呈现反馈、客服授权查看或账号注销入口。
- 用户审阅后确认页面可用性；资产链接留在工单，不将原型扩展为正式开发。

## Answer

### 确认范围与页面组织

用户确认采用固定左侧导航、独立家庭详情页、模板编辑页并排对照。导航按权限呈现下列模块，当前账号与角色保持可见。

| 模块 | 页面组织与主要路径 |
| --- | --- |
| 运行概况 | 按家庭组建、家务协作、兑换与兑现分组展示既定七项全平台指标；提供今日、近 7 日、近 30 日及口径说明，通过独立快捷入口进入模板或家庭管理 |
| 家庭管理 | 名称或编号检索、状态筛选；列表进入独立家庭详情，再处理单户停用或恢复 |
| 公共家务预设 | 名称或说明搜索，状态、区域、周期筛选；进入新建草稿或编辑与预览 |
| 默认特权模板 | 名称或说明搜索、状态筛选；进入新建草稿或编辑与预览，不增设特权分类 |
| 管理员管理 | 独立账号列表，新增、角色和启停路径；变更原因与影响确认 |
| 操作记录 | 按角色展示全部或本人操作记录，可按对象、动作等检索，不提供改删日志入口 |

菜单可见性、家庭字段、指标口径及管理员能力严格引用[平台权限决议](09-admin-permissions.md#answer)，不通过页面增加家庭私有内容、反馈、客服授权、账号注销或代操作入口。

### 家庭列表、详情与状态操作

- 列表使用已批准的最少字段，详情补充成员资料及家庭状态操作记录；不增加私有记录下钻或批量操作。
- 采用“定位家庭 → 独立详情 → 填写双方可见原因 → 查看影响并再次确认 → 显示最新结果”的单户路径。
- 停用确认说明暂停协作写入、保留关系历史积分及待兑现；恢复确认说明沿原日历继续、不补发停用期间待办、原单项暂停保持暂停。详细业务结果继续以平台权限决议为准。
- 操作成功后留在详情页，呈现最新状态、原因和时间；停用成功后可进入恢复。恢复同样需要原因与确认，不采用一键撤销。
- 归档详情只读，不显示恢复动作。恢复提交前已归档时，明确提示未恢复、不可再次恢复。
- 明确失败显示未生效并保留原因；权限变化或账号停用后拒绝旧页面操作，不误报成功。

### 模板保存、发布、下架与恢复

- 编辑页并排展示“当前发布内容”和“本次编辑内容”；窄屏上下排列且保持标题明确。已下架时左侧标为最后发布内容，明确当前不能新选用。
- “保存草稿／保存编辑”与“预览并发布”分开。已发布模板存在编辑稿时，同时标记已发布状态与未发布修改，不能将保存成功表示为发布成功。
- 建议周期使用类型选择、星期勾选、间隔数值或日期输入。草稿可以不完整；保存及发布校验失败保留已填内容。发布前定位缺项、预览家庭可见内容并说明生效范围。
- 发布、下架与重新发布均明确：影响后续新选用，不覆盖家庭已有的家务、心愿或兑换约定；特权选用仍需兑现人本人确认。
- 已下架模板分开提供“重新发布最后发布内容”与编辑后预览发布。前者不顺带发布编辑稿，保留原模板来源。
- 放弃编辑保留最后发布内容；只有从未发布的草稿可删除。误发布通过修正后重新发布处理，不增加完整版本回滚。
- 当前排序控件采用数值越小越靠前。排序、生效、同源去重与首批内容库标准继续引用[公共模板决议](08-public-templates.md#answer)。

### 管理员、日志与异常状态

- 家庭和管理员管理入口仅向超级管理员呈现；运营管理员保留模板、运行概况及本人操作记录。直接访问受限页面时显示权限不足，并提供有权访问的返回入口，不呈现受限字段。
- 管理员角色和启停变更展示变更前后状态、原因与影响；最后一名有效超级管理员的停用或降级不可生效，页面解释原因。
- 新增管理员以独立账号及固定角色为页面路径；真实登录、凭证生成和交付机制没有在本原型中决定或实现，不将演示表单视为完整认证流程。
- 操作记录以只读列表展示既定留痕字段，权限范围沿用平台权限决议；对象编号不成为查看家庭私有内容的入口。
- 区分加载中、无数据、筛选无匹配、读取失败、操作明确失败和权限不足；无匹配可清除筛选，读取失败可重新读取，明确失败在状态允许时保留输入重试。
