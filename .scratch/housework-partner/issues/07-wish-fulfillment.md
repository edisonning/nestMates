## Question

从默认特权或自定义心愿到花分兑换、伴侣履约和确认完成，需要哪些角色、状态与取消规则？

- 谁能创建、定价、修改或下架心愿；由谁提供的承诺是否必须事先同意。
- 沿用[积分决议](05-points-ledger.md#answer)的兑换扣减可用积分、余额不足不能新增兑换、取消按原实扣金额退分及不向履约者转账口径，明确兑换确认步骤、重复兑换和价格变化如何处理；已兑换项目是否保留当时的服务约定。
- 待履约由谁负责，谁盖章确认；能否拒绝、取消、延期或退款，如何避免未经对方同意产生义务。
- “免洗碗卡”是否需要改变真实家务分配或只代表双方线下约定；如改变，需与分配规则衔接。
- 按[已决家庭生命周期](01-family-membership.md#answer)处理归档取消与退分，明确已完成、已取消或同时正在兑现的边界，防止重复退分；心愿删除和长期未兑现时如何关闭承诺仍待决定。
- 用肩颈按摩、免洗碗卡及自定义心愿分别走通成功兑现与取消路径。

## Answer

### 心愿与角色

- 首版仅兑换本家庭伴侣提供的服务或特权，不能兑换本人提供的心愿。家庭成员侧的心愿与兑换记录仅本家庭双方可见；归档后原成员只读，不能迁移至新家庭。
- 双方均可提出心愿，但提出人不等于兑现人。开放兑换前必须明确兑现人，由兑现人本人确认内容与价格；默认特权也不能直接成为伴侣义务。
- 未确认或拒绝确认的心愿不可兑换，不产生履约义务；内容或价格调整后可再次交由兑现人确认。本人创建并提供的心愿可由本人确认开放，供伴侣兑换。
- 单人阶段可以先创建心愿，伴侣加入并确认后再兑换；不提供自己花分、自己兑现的路径。
- 心愿价格为大于 0 的整数积分，由家庭自行约定，不套用家务 10～100 分十档范围，首版不提供免费兑换。

### 修改、下架与移除

- 双方均可修改心愿内容或价格，修改后暂停新兑换，由兑现人重新确认才开放。双方均可下架或移除心愿。
- 下架停止新兑换，可由兑现人确认后重新开放。移除使心愿从目录消失，首版不提供移除后的恢复入口。
- 已有兑换保留当时的内容、价格、兑现人和处理历史，不因后续修改、下架或移除而改变或消失。
- 移除心愿不自动取消或退分；对应待兑现记录继续可查、可盖章或主动取消。心愿目录和兑换记录的生命周期分别处理。

### 兑换成立与积分

- 兑换人核对服务内容、兑现人、价格与扣分后余额，主动确认兑换。已开放心愿不需要兑现人逐笔审批，成功时扣减可用积分并产生一笔待兑现记录。
- 余额不足或心愿已不可兑换时，不成立有效兑换、不扣分。余额更正为负数时，既有兑换不自动取消，遵守[贡献积分与可用积分决议](05-points-ledger.md#answer)。
- 同一兑换人对同一心愿，同时最多保留一笔未关闭兑换；已完成或已取消后可再次兑换，不同心愿可同时兑换。
- 扣分只减少兑换人的可用积分，不改变贡献积分或协作天平，也不向兑现人转账。盖章完成不另行发放积分。
- 取消只退原实扣金额至原兑换人，后续改价不影响退分，不改变贡献积分。重复点击、结果不明后的重试不能重复兑换、扣分或退分。

### 兑现与关闭

兑换只包含待兑现、已完成、已取消三种状态，不设置兑现人提交、待确认、取消审批或申诉状态。

| 当前状态 | 操作与权限 | 结果 | 积分处理 |
| --- | --- | --- | --- |
| 尚未兑换 | 符合资格的兑换人核对并确认兑换 | 待兑现 | 扣减本次价格 |
| 待兑现 | 兑换人确认已收到约定服务，经过盖章前再次确认 | 已完成 | 不再增减 |
| 待兑现 | 家庭任一方直接取消，无须另一方同意 | 已取消 | 原实扣金额退回一次 |
| 待兑现 | 家庭归档 | 已取消 | 原实扣金额退回归档钱包一次 |
| 已完成／已取消 | 再次盖章、取消或重新打开 | 保持原关闭结果 | 不再增减 |

- 兑现人不能代替兑换人盖章。系统以兑换人的盖章作为完成边界，不自动判断线下履约：即使线下已经提供服务，只要尚未盖章，仍属于待兑现且可取消。
- 线下尚未兑现时继续保留待兑现，不需要“退回”操作。双方可以继续协商兑现，也可由任一方直接取消。
- 不强制选择兑现日期；可在备注中记录双方约定时间，延期协商后更新备注并保留修改记录。不罚分，不因日期经过自动完成或退款。
- 长期未兑现可由任一方主动取消，不依赖对方响应。双方都不处理时继续保留待兑现，不因长期搁置推定完成或取消。
- 已完成和已取消是最终状态，历史保留、不重新打开；首版不支持撤销盖章、部分退款或追加扣分。误盖章也不能自行撤销，因此盖章前再次确认并说明后果。

### 家务特权与家务记录

- 免洗碗卡等特权记录双方线下约定，不自动改派、跳过家务或生成打卡。
- 若伴侣接手已有待办，使用[既有分工决议](03-assignment-rotation.md#answer)中的“本次接手”，由实际完成人以本人账号打卡；所得家务积分按既有计分规则计算。
- 兑换的完成或取消不改变独立家务记录。已经发生的接手、打卡，不因卡片取消而自动撤回；需要调整家务时沿用原家务流程。

### 同时操作与家庭归档

- 以先成功生效的有效操作为准，后续操作不能覆盖关闭结果。
- 取消先成功：退分一次，随后盖章不能成功；盖章先成功：保留已完成，取消不能成功、不退分。双方同时取消也只退一次。
- 归档先成功：待兑现自动取消退分，随后不能盖章；盖章先成功：归档保留已完成，不退分。已取消记录在归档时不重复退分。
- 沿用[家庭生命周期决议](01-family-membership.md#answer)：归档钱包中的余额（含退分）仅供原成员查看，不可消费、迁移或继续操作；未完成兑换不能阻止归档。
- 改价、下架或移除先成功：旧确认页不能按旧内容继续兑换，应提示刷新核对；兑换先成功：保留当时约定，不因随后目录变化追改。
- 网络返回不明时须能重新查询已有处理结果；重试不能被当作一次新的兑换，亦不能造成额外扣分、退款或状态变更。

### 具体场景核对

下列价格仅用于规则推演，不是默认特权的定价；甲为兑换人，乙为兑现人。每行均从独立的待兑换场景开始。

| 场景 | 成功兑现路径 | 取消路径 |
| --- | --- | --- |
| 肩颈按摩 20 分钟，60 分 | 乙确认开放；甲有 100 分，兑换后剩 40；乙线下按摩，甲再次确认并盖章为已完成，余额仍为 40，不能取消 | 尚未盖章时任一方取消，退回 60，甲恢复 100；即使按摩已发生但尚未盖章，也按此边界处理 |
| 免洗碗卡，30 分 | 甲有 100 分，兑换后剩 70；乙通过本次接手处理实际洗碗待办并本人打卡；甲确认免洗碗约定已兑现后盖章，卡片不自动打卡 | 尚未盖章时任一方取消，退回 30，甲恢复 100；已经发生的接手或打卡不会随退款自动撤回 |
| 自定义“周末做一次早餐”，120 分 | 任一方提出，乙确认内容与价格；甲有 150 分，兑换后剩 30；乙完成早餐，甲盖章，余额仍为 30 | 后续心愿改为 150 分或从目录移除，原兑换仍按 120 分保留；任一方取消原兑换，退回 120，甲恢复 150 |

| 边界场景 | 预期结果 |
| --- | --- |
| 同一心愿仍有一笔待兑现，再次兑换 | 不产生第二笔有效兑换，不重复扣分；取消或完成后可重新兑换 |
| 没有伴侣、兑换本人承诺或余额不足 | 不能成立兑换，不扣分 |
| 对方未同意新心愿或修改后的内容 | 保持不可兑换，不产生义务；既有兑换继续按原约定处理 |
| 长期未兑现、对方不回应 | 任一方可以直接取消退分；也可继续保留等待，不自动判定完成 |
| 取消和盖章同时发生 | 先成功的操作决定唯一关闭结果，取消先成功只退一次，完成先成功不退 |
| 尚有待兑现时家庭归档 | 自动取消，原实扣退入归档钱包；已完成不退，已取消不重复退 |

核对结果：以上成功、取消与边界路径均能按已确认规则得到明确状态和账目结果。此处为文档推演，页面交互、重试和同时操作仍须在后续原型与实现中验证。
