## Question

如何区分公共家务预设、家庭自定义家务与每次待执行的家务，使每日、每周和定期深度清洁具有一致的生成、到期与修改规则？

- 六个功能区的归属是否固定，跨区域家务如何归类；家庭是否能自行扩展分类。
- 预设载入后与公共模板是什么关系；重复载入、个性化修改、停用与删除如何影响已有任务。
- 周期的开始、截止、时区与定期安排如何定义；逾期、跳过、暂停和提前完成如何处理。
- 修改周期或难度时，对当前待办和未来任务分别产生什么影响；原预计时长问题已由[打卡与反馈决议](04-checkin-and-feedback.md#answer)移除。
- 区域、负责人、周期筛选与搜索基于什么对象；没有匹配结果和没有任务时如何引导。
- 用每日洗碗、每周换床品和定期洗油烟机滤网贯穿规则。

## Answer

### 家务结构、预设与分类

- 公共家务预设是平台模板；家庭家务是本家庭的安排；本次待办是该安排的一次执行。完成一次待办不删除长期家务。
- 载入后形成独立的家庭家务，家庭可个性化修改；平台更新公共模板不自动覆盖家庭安排。
- 默认跳过已存在的同源家务，包括暂停中的家务，保留家庭修改；确需多份时主动复制并分别命名，例如主卧与次卧换床品。
- 六个区固定为厨房烹饪、客厅公共区、卧室衣物、卫浴清洁、阳台宠植、综合事务。每项家务归一个区，跨区域事务归综合事务；首版不增加自定义区域，但可自由创建家务。

### 日历安排

- 支持每天、每周指定星期且可多选、每隔 N 个月的指定日期、从指定首次日期起每隔 N 天，以及一次性指定日期。
- 只安排日期，不填写具体时刻；统一按北京时间，当天结束后才算逾期。
- 计划按原定日历执行，不随实际完成日期顺延。月度计划遇到不存在的日期，取当月最后一天；该次调整不改变长期指定日期。
- 一次性家务完成后不重复，与周期家务共用分工、打卡和积分流程。

### 逾期与提前完成

- 周期逾期待办保留到下一次计划日期到来；届时旧待办转为“未完成”历史记录，展示新一期，避免同一周期家务不断积压。
- 一次性家务没有下一期，逾期后仍保留至完成或主动跳过；另行暂停或删除时按下方操作规则处理。
- 允许提前完成最近一次待办，明确显示原定日期；原计划日结束前不开放更后一期，不因提前完成改变后续日历。有当前逾期待办时先处理当前这次。
- 已提前完成的那一次到原定日期时不应重复要求完成。具体生成、生效和日期调整的交叉边界由后续日期边界工单确认。

### 跳过、暂停、修改与删除

- 跳过本次：记录“已跳过”，不算完成、不得积分，后续周期照常。
- 暂停家务：关闭当前未完成待办并注明暂停；暂停期间不产生新待办。恢复后按原日历继续，不补发暂停期间任务。
- 修改家庭家务：默认仅影响后续新待办，当前已出现的待办与历史不变；确需调整当前一次时使用“仅修改本次”，不改变长期安排。已完成记录不随家庭家务修改而改变。
- 删除家庭家务：操作前提示影响并确认；停止生成新待办，当前未完成待办标记取消，历史打卡和积分记录保留。暂时不用可暂停，仅不做一次可跳过。
- 上述规则不替代[家庭生命周期决议](01-family-membership.md#answer)：家庭归档后不能通过恢复家务、载入预设或复制家务继续协作。

### 任务大厅

- 默认展示今天要做的与仍可处理的逾期待办，列表对象是本次待办。
- 单独入口预览未来安排，按已决限制提前完成最近一期；“全部家务”管理家庭家务，不与一次待办混为一张列表。
- 区域、负责人、周期可组合筛选；关键词搜索家务名称和说明。筛选作用于所在视图的对象，负责人具体选项与分配规则保持一致。
- 无匹配结果提供清除筛选；家庭尚无家务时，引导载入预设或自行创建。具体页面布局和操作反馈由小程序原型工单确认。

### 关键场景的预期结果

| 场景 | 预期结果 |
| --- | --- |
| 昨天的每日洗碗没做，今天到来 | 昨天转为未完成历史，今天展示新一期，不积压两条当前待办 |
| 每周日换床品，拖到周一做 | 仍可完成该次；下一次继续安排在周日 |
| 周六提前完成周日换床品 | 计为该周日的一次任务，不立即开放更后一期，也不在周日重复生成待完成要求 |
| 每月 31 日清洁，进入四月和五月 | 四月安排 30 日，五月回到原定 31 日，不永久改成每月 30 日 |
| 临时整理搬家纸箱逾期 | 没有下一期自动替换，仍可完成或主动跳过 |
| 出差暂停家务后恢复 | 暂停期间不产生待办，不补发期间任务，沿原日历继续 |
| 已修改换床品安排，再载入同源预设 | 不重复添加、不覆盖修改；需要第二份时主动复制并命名 |
| 删除有历史打卡的家庭家务 | 停止未来任务、取消当前未完成待办，历史打卡与积分仍在 |

以上为产品预期和文档一致性核对，不代表已通过功能测试或页面验收。
