## Answer

### 本人打卡与字段范围

- 首版不设置家务耗时属性：家务与预设不要求预计耗时，打卡不采集实际耗时，动态与天平不展示或汇总劳作时长，计分不依赖耗时字段。此决议覆盖此前关于时长的规划输入；心愿名称中“按摩 20 分钟”等服务内容不属于家务耗时属性。
- 打卡表单无必填项，心得、感谢留言、实际完成日期均可不填写。本人身份由账号确定，不允许切换打卡人或代打卡。
- 沿用[分配与轮流决议](03-assignment-rotation.md#answer)：当前公共待办先认领，非负责人先本次接手，再本人打卡；历史补记按下方独立规则处理。
- 本人提交成功即生效，无需伴侣确认。比心表达认可，不是完成生效条件。
- 天平按完成家务的贡献分值呈现双方比例，简单家务分低、复杂家务分高；完成次数作为辅助信息。积分用于兑换心愿或特权，具体定分、统计期、贡献累计与可用余额的关系由后续工单决定。

### 日期与补记范围

- 日期统一沿用北京时间。正常打卡默认实际完成日期为当天，可修改；计划日期与实际完成日期是不同信息，提前完成仍属于原计划的那一次。
- 历史补记的实际完成日期可不填。未填时展示计划日期与补记时间，不推测实际完成日期；填了则同时展示实际完成日期，并明确补记标识。
- 填写或更正的实际完成日期不能晚于今天，也不能早于本人加入该家庭的日期。补记未完成历史表示补录该次关闭前已经做过的家务，不是事后重新执行旧任务。
- 家庭使用中不设固定补记天数限制，但仅允许补记符合条件的记录，不补造不存在的历史任务。家庭归档后只读。

| 对象 | 本人记录完成的路径 |
| --- | --- |
| 仍可处理的当前或逾期待办 | 沿当前分工打卡，可补填实际完成日期 |
| 周期更替后留下的未完成历史 | 从独立历史补记入口操作，不恢复为当前待办 |
| 历史原计划归伴侣，实际由本人完成 | 本人确认“这次实际由我完成”后补记，保留原计划负责人，实际完成人记录本人 |
| 公共池无人认领的未完成历史 | 同样可以本人确认后补记，保留原待认领信息 |
| 已有有效完成记录 | 不允许再补记第二条有效完成 |
| 已跳过，或因暂停、删除关闭的记录 | 首版不开放补记 |
| 已归档家庭 | 不允许新增、补记或更正 |

历史补记不改变当前分工和后续轮流，不能替伴侣记录完成。实际日期缺失时的贡献统计期归属由积分工单明确，不在本工单默认使用计划日期替代实际日期。

### 有效完成与重复提交

- 同一次待办最多有一条有效完成记录。撤销记录可以保留，但不继续作为有效完成；重新打卡仍受本次状态与身份规则约束。
- 重复点击和网络重试返回同一次结果，不重复增加次数、积分或撒花。双方同时尝试历史补记也不能产生两条有效完成。
- 提交结果不明时显示“正在确认打卡结果”，查明后展示成功或允许重试；明确失败时保留已填写内容。
- 打卡与改派、接手等冲突沿用分配决议：先成功的操作生效，后续操作按最新状态判断；不按旧页面身份改写已完成记录。

### 动态、文字更正与历史保留

- 动态打卡簿仅本家庭成员可见，按打卡提交时间倒序，展示实际完成人、时间信息与分值。补记显示在本次提交的位置，不按过去的完成日期埋入旧动态。
- 本人可以编辑或清空心得、感谢留言，显示“已编辑”，保留更正痕迹和已有比心；不提供评论区。
- 本人可更正实际完成日期并保留痕迹，遵守相同日期边界。更正不新增完成、不再次撒花；涉及积分与统计期调整时按积分工单规则处理。
- 不允许直接修改实际完成人或对应哪次任务；记错需由原打卡人撤销，再按适用规则重新本人打卡。伴侣不能直接编辑、删除或撤销对方的完成记录。
- 历史持续保留；家庭归档后双方只读查看，不能继续编辑、撤销或比心。新家庭与新伴侣的访问边界沿用[家庭生命周期决议](01-family-membership.md#answer)。

### 撤销权限与恢复状态

- 仅原打卡人能撤销，无需伴侣审批；撤销原因必填，操作痕迹双方可见。打卡表单无必填不等于撤销原因可以省略。
- 家庭使用中不设固定撤销天数限制。操作前说明该次恢复状态和积分影响，成功后原记录明确显示“已撤销”。
- 撤销不重排后续轮流，也不自动恢复接手前的伴侣为当前负责人。

| 撤销时的情况 | 恢复结果 |
| --- | --- |
| 该次仍处于可处理期间 | 恢复待办，负责人保留为撤销前的完成人 |
| 恢复后需要调整本次分工 | 可按既有规则再次接手、改派或放回公共池 |
| 已进入后续周期，或原本是未完成历史的补记 | 恢复未完成历史，不重新成为当前待办，不影响新一期 |
| 家务已暂停或删除 | 不重新开放待办，保留撤销及关闭信息 |
| 家庭已经归档 | 不允许撤销，保持只读 |

- 撤销后不再将原记录当作有效完成计入贡献。积分扣回、余额不足和关联兑换的处理由[贡献积分与可用积分如何计算和更正](05-points-ledger.md)决定，不在这里推定负余额、退款或取消兑换策略。
- 恢复待办后重新打卡，或恢复未完成历史后再次补记，均按本工单对应资格办理，不绕过暂停、删除和归档等关闭边界。

### 比心与可见反馈

- 仅伴侣可给有效完成记录比心，每条最多一个，再次点击可取消，不影响积分；单人阶段不提供给自己比心的路径。
- 双方看到一致的最终状态，快速重复点击不会产生多个比心。
- 撤销后原比心随原记录保留展示，但不能继续互动；重新打卡不会继承旧记录的比心。

| 用户路径 | 产品预期 |
| --- | --- |
| 本人完成家务，不填写任何表单项并提交 | 直接完成，展示本次分值，简单撒花一次，动态出现记录 |
| 符合条件的历史补记成功 | 历史完成生效，展示分值并撒花一次，动态注明补记；不重开当前待办 |
| 提交后网络中断，用户重试 | 先确认原结果，最终仅一条有效完成，不重复计分或撒花 |
| 修改心得或完成日期 | 提示“已更新”，保留更正痕迹，不作为新增完成 |
| 接手伴侣本次家务并完成，仍在可处理期间撤销 | 原记录显示已撤销，待办恢复给本人，后续轮次不变 |
| 新一期出现后撤销旧一期完成 | 旧一期恢复未完成历史，新一期保持原安排 |
| 撤销有比心的记录后重新打卡 | 旧记录与比心只读留痕，新记录独立等待伴侣比心 |
| 家庭归档后查看打卡簿 | 历史可读，打卡、补记、更正、撤销与比心入口均不可操作 |
