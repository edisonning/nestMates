# 协作天平交互粗原型

仅用于回答[协作天平怎样表达比例而不要求五五开](../../issues/06-balance-prototype.md)中的视觉和交互问题。模拟数据、内存状态，无真实账号，无数据持久化，不是正式小程序。

## 打开

可直接用浏览器打开 `index.html`，或在项目根目录执行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory .scratch/housework-partner/prototypes/balance-prototype
```

访问 `http://127.0.0.1:8766/?variant=B`。默认打开已确认的 B「双方对照」。A 为天平居中，C 为月度记录，两者保留用于对照。底部按钮或左右方向键切换；输入控件聚焦时不抢占方向键。页面会保留所选月份和当前模拟状态，刷新后恢复模拟初值。

## 本轮已确认与保留边界

- 三种布局对相同贡献数据的可理解性。
- 倾斜幅度候选：按双方真实贡献差占总贡献的比例，映射至最多 13 度；分多的一方下沉，占比数字保持真实，不因视觉限幅修改比例。界面取整显示占比，两人之和为 100%；双方均为零或等待伴侣时显示“—”。最大 13 度、整数占比及当前提示语已获用户本轮确认。
- 提示语已确认；记录排序、展示条数及完整积分页面仍由后续页面工单完善，不将原型的演示简化当作最终规则。
- 可切换七种状态；演示补记、日期更正、清空日期、撤销、消费与退款。归档场景关闭模拟写操作。
- 模拟钱包从明确标注的其他历史收支结余开始，不由屏幕上显示的少量月度记录反推全部历史余额。

## 边界

正式心愿流程尚由相应工单决定；演示按钮只核对积分效果，不代表可任意兑换或退款。邀请按钮不发出真实邀请。用户已选定 B「双方对照」，本工单确认范围为协作天平粗原型；完整小程序路径仍待后续工单。
