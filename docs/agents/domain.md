# Domain Docs

本项目采用 single-context 领域文档布局：

- 根目录 `CONTEXT.md`：领域术语和业务上下文。
- 根目录 `docs/adr/`：架构决策记录，文件使用编号前缀，
  如 `0001-<decision-slug>.md`。

## 探索前读取

探索代码前，读取根目录 `CONTEXT.md`，
并阅读 `docs/adr/` 中与当前工作相关的决策。

这些文件或目录不存在时，静默继续。
由 `/domain-modeling` 在术语或决策实际明确后按需创建。

## 使用领域术语

在工单、设计方案、假设和测试中命名领域概念时，
使用 `CONTEXT.md` 中定义的术语。

所需概念尚未收录时，先检查是否已有等价术语；
确有缺口则记录给 `/domain-modeling`。

## 显式说明决策冲突

方案与现有 ADR 冲突时，指出对应 ADR，
解释冲突以及重新讨论该决策的理由。
