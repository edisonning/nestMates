# Triage Labels

本项目使用默认的五个分诊角色名称。
本地 Markdown 工单通过 `Status:` 行记录对应状态。

| 技能中的角色 | 本项目状态 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格明确，可以交给代理执行 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

当技能要求应用某个分诊角色时，使用表中对应的项目状态。
后续需要自定义名称时，修改“本项目状态”列。
